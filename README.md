# AI Workplace Productivity Assistant

## 📌 Project Overview
The **AI Workplace Productivity Assistant** is a modern, responsive web application designed to automate workplace tasks using AI tools such as ChatGPT and Lovable AI.  
This project demonstrates practical AI implementation, strong prompt engineering, real-world problem solving, and responsible AI usage.

---

## ✨ Features
1. **Smart Email Generator**
   - Generates professional emails
   - Supports different tones (formal, friendly, persuasive)
   - Provides subject line + body

2. **Meeting Notes Summarizer**
   - Summarizes long meeting transcripts
   - Extracts key decisions, action items, and deadlines
   - Outputs concise, structured summaries

3. **AI Task Planner / Scheduler**
   - Creates daily or weekly schedules
   - Prioritizes tasks by urgency and importance
   - Outputs clear, actionable plans
